# Amazon Cart Exporter

Manually right-clicking every item in an Amazon cart is tedious. This extension grabs the title, cleaned URL, and price of all active items in your cart and copies them to your clipboard as JSON.

## How to Install

1. Unpack these files into a folder named `amazon-cart-exporter`.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the folder you created.
5. Pin the extension to your toolbar.
6. Go to your active Amazon Cart page, click the extension icon, and hit Export!
